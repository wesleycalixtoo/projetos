# Atividade - estr. De Dados
> Desenvolva um algoritmo com a linguagem utilizada na disciplina, que resolva o seguinte problema:
	>> 'Uma loja de eletrônicos quer digitalizar o controle do seu estoque. Cada produto possui um código numérico único (ID) e um nome.'
	>> Os produtos são armazenados fisicamente em caixas organizadas por código, com limite de 10 produtos. Dessa forma, para encontrar um produto, o funcionário nunca olha todas as caixas.

> Você deve desenvolver um sistema que:
	>> Permita cadastrar produtos com seu código e nome.
	>> Exiba todos os produtos em ordem crescente de código.
	>> Simule a busca de um produto por código, respeitando a lógica de navegação que o funcionário utiliza.
